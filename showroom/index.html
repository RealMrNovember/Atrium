Questions

Does Atrium send my code or chats anywhere?

No. Your code, chats and project memory stay on your computer. Agents run through the AI tool you choose — with a local model nothing leaves the machine. Atrium itself only checks for updates and release notes, and — only if you use them — sends your account details and the messages you write.

Can I use Atrium without Claude?

Yes. Any agent can run on OpenAI Codex, Gemini CLI, an OpenAI-compatible server or a local model through Ollama, which Atrium installs for you.

Do I need a powerful computer for local AI?

No. Small models run on almost any recent computer, even without a graphics card. The Local AI page measures your machine and recommends a model.

How much does it cost?

Atrium is free. Agents use your own Claude, ChatGPT or Google plan — or cost nothing with local models. For Claude you set per-run and daily caps.

Do I need an account?

No. Atrium works fully without one. A free account is only needed to send feedback or bug reports and read our answers — sign up with email or Google, delete it any time.

Can I manage several companies?

Yes. Add as many as you like; each has its own projects, team, memory, reports and default AI tool.

Is it safe to let agents work on my projects?

Agents are read-only by default, never open secret files, never commit, push or publish, and treat web pages and file contents as data — not instructions.
