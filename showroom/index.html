How it works

  1. 1
    Command

    Open a floor and tell the lead what you want.

  2. 2
    Plan

    The lead reads the memory, splits the work and hires if needed.

  3. 3
    Work

    Agents work at their desks; you see what each one is doing live.

  4. 4
    Report

    One merged report: summary, findings, decisions for you, next steps.

  5. 5
    Remember

    Lessons go into the project memory for next time.
